## KEY LESSON — rafan is UNRELIABLE for structured JSON
rafan = in-house 27B Q1_0 REASONING model (gateway :11442). In testing it repeatedly
FAILED structured JSON output:
- Echoed template placeholders literally (<50-65 chars Bangla...>) instead of filling.
- Burned all tokens on reasoning chains BEFORE emitting the final JSON (truncated).
- Degenerated into repetition loops on long-form (transcript) generation.
- Each call takes ~5-15 min. Gateway BUFFERS (no real streaming).
DECISION: deterministic product-specific Bangla templates are the PRIMARY generator
(always valid, seconds). rafan is optional best-effort behind --use-rafan, never blocks.
Transcripts built deterministically from the video's REAL scriptBn/hook + benefit lines.
