# V16.4 — Green Button Text Invisible — Fixed (screenshot-grounded)

Date: 2026-09-16 01:14 +06. Source: `Screenshot 2026-09-16 011412.png` (every green button, all pages).

## Symptom

Green buttons/pills rendered with NO visible text — top-bar green action buttons, sidebar credit button, KPI icon chips, emerald action buttons across `/admin`, `/dashboard/*`, `/admin/tv`, payments.

## Root cause (two holes left by V16.3)

V16.3 remapped the cream text hexes and its `--check` passed — but it only tested *light-text-on-light-surface*. Two green-button cases were outside that check:

1. **BRAND regex missed `emerald-*` and gradient.** `paper-theme-convert.py`'s brand-surface detection listed `green/blue/amber/gradient` but not **emerald** and not `from-[#0E7C3A]`. So `text-white` sitting on `bg-emerald-600` / gradient-green buttons was flipped to ink → **ink-on-green ≈ 1.2:1, invisible**. Hit `--admin` toggles, `--team`, `--api-keys`, `--affiliate`, `--payments`, `--market`, `--admin/tv` Start Stream, and the sidebar credit card's bKash area.
2. **Parent-context.** Some elements put the green bg on a PARENT className while `text-white` lived in a CHILD (CreditMeter gradient card, product-card active branch, KPI gradient icon chips). The per-string check can't see ancestors, so the child kept ink → invisible.
3. **No text color at all.** Emerald buttons whose string had only `text-sm` (a size, not a color) inherited **ink from the paper-theme parent** → invisible.

## Fix

New `scripts/fix-green-buttons.py` (rerunnable, with `--check`):

- **Pass 1 (string-level):** inside any quoted className with a **solid** green bg (`bg-[#0E7C3A|146E2B|1A7A33]` no-opacity, `bg-emerald|green-600|700`, `from-[#0E7C3A]` gradient) → ink-family text tokens become `text-white` (white/70 for soft variants); strings with no color token get `text-white` appended. Tinted greens (`/10 /15 /20`) are excluded (light surfaces); bars, skeletons and progress fills are skipped by guard.
- **Pass 2 (targeted):** parent-context cases — CreditMeter gradient card, product-card active state (title/tagline/chip), KPI gradient chips, admin table avatar/model chips — set to white; the cream-on-cream `from-[#FDF8EC] to-[#F6EBD2]` KPI accent changed to `from-amber-600 to-amber-400` so its white icon reads.
- Cleanup: removed stray `text-white` sprayed on empty decorative dots/bars; reverted two tinted banners that pass 1 mis-tagged.

Checks: `fix-green-buttons.py --check` → **OK: all solid-green surfaces carry white text**; `fix-paper-contrast.py --check` → **0 invisible tokens**.
