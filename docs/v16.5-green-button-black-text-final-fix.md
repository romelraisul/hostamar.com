## Root cause of what was actually broken

`layout.tsx:168` — the nav ICON carries its own ternary: `isActive ? 'text-[#1C1917]' : 'text-[#57534E]'`. V16.4's string-level pass saw `text-white` in the PARENT link string (active branch) and never looked at the icon's own string → **ink icon on green**. Same pattern in `chat-client.tsx:200`: timestamp `text-[#1C1917]/70` inside the user's green bubble.

Second finding: those sibling-ternary patterns were invisible to both V16.4 checks because the green bg lives on a different line/string than the ink text.
