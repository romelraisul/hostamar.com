## scripts/parse_upstream_changelog.py

**Purpose:** Parse upstream release notes (Gemini API, Hermes Agent) into structured JSON for changelog building.

**Usage:**
```bash
python scripts/parse_upstream_changelog.py \
  --source gemini-api \
  --output /tmp/upstream_gemini.json

python scripts/build_changelog.py \
  --upstream /tmp/upstream_gemini.json \
  --since v17.0.0 \
  --output docs/changelog/v17.1.0-release-notes.md
```

**Output format:**
```json
{
  "version": "latest",
  "date": "2026-09-17",
  "source": "gemini-api",
  "features": [{"text": "...", "hostamar_impact": "low|medium|high", "notes": "..."}],
  "fixes": [{"text": "...", "hostamar_impact": "...", "notes": "..."}],
  "breaking": [{"text": "...", "hostamar_impact": "...", "notes": "..."}],
  "deprecated": [{"text": "...", "hostamar_impact": "...", "notes": "..."}],
  "summary": "Parsed X entries: Y features, Z fixes, W breaking. N high-impact."
}
```

**hostamar_impact levels:**
- `low` — internal Hermes change, no action
- `medium` — new feature/tool available, optional adoption
- `high` — breaking change, new capability, security fix — must act

**What it parses:**
- Gemini API release notes from `https://ai.google.dev/gemini-api/docs/release-notes`
- HTML parsing via stdlib `html.parser` (no extra deps needed)
- Classifies entries as feature/fix/breaking/deprecated
- Assesses hostamar-build impact based on keywords (security, auth, new model, vision, audio, video, skill, tool, API)

### Build Pipeline

```
git push origin main
  → Vercel detects push on main
  → Build:
    1. npm ci (install deps from lockfile)
    2. npx prisma generate (Prisma client)
    3. npm run build (Next.js build + static export)
       - next build
       - Static pages prerendered
       - API routes bundled
       - Output: .next/ directory
  → Build FAIL: deployment fails, old version stays live
  → Build PASS: deploy to production
    - Edge config applied (headers, redirects, rewrites)
    - Custom domain: hostamar.com → Vercel
```
