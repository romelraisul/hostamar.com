## Root Causes

1. **Vercel CLI deploy timeout (420s)**: Large build output (~600MB `.vercel/output`) upload fails on slow WSL→Vercel link
2. **Network instability**: npm registry timeouts prevent `pnpm install` → no `prisma generate` → build fails
3. **IPv6 localhost mismatch**: `localhost:8088` resolves to `::1` → connection reset; `127.0.0.1:8088` works
4. **Missing vercel.json historically**: No explicit build config caused function count explosion (381 > 12 Hobby limit) → forced `output: 'standalone'` which Vercel builder struggles with
5. **GitHub suspended**: No git-triggered deploys possible; must use Vercel CLI only
